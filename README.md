# RAGNAR Technologies

Company presentation website: https://ragnar-technologies.vercel.app/

## Development

Node.js 22 or newer. No third-party packages, API keys, paid services or installation required.

```sh
npm run build
npm run dev
```

Open http://localhost:4173. Build copies validated static assets into `dist/`.
Vercel uses `vercel.json` to build and publish `dist/`.

## Content and behaviour

English by default; complete Portuguese and French text through the language selector.
The choice is saved locally when browser storage is available. The English content remains readable without JavaScript.

Home, Solutions, Projects, About and Contact are accessible sections of one page.
Hospitality AI and Construction AI are development/demonstration projects. Workflow examples are predefined illustrations, not operational AI, verified product capabilities, customer cases or production results.
The copy-brief control only writes a template to the visitor's clipboard. No messages are sent and no form data is collected.
The Contact link points to the verified repository owner's public GitHub profile; no business email or physical address is asserted.
RAGNAR Sport is not marketed here.

## Privacy and accessibility

No analytics, external fonts, cookies, trackers or remote runtime requests.
Semantic landmarks, skip link, keyboard focus, mobile navigation with Escape support, descriptive controls and reduced-motion support.
